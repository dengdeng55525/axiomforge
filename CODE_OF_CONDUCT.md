# Contributor Covenant Code of Conduct

## Our pledge

We want this project to remain a respectful, constructive and technically honest space for everyone who participates. Contributions must not expose credentials, private data, unsafe executable samples or unsupported performance claims.

## Expected behavior

- Be respectful and specific in reviews and discussions.
- Prefer reproducible evidence over unsupported claims.
- State limitations, failed experiments and environment assumptions.
- Protect personal data, API keys and third-party license obligations.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, credential exposure, malicious code samples and deliberate falsification of test or benchmark results are not acceptable.

## Enforcement

Report conduct or security concerns privately through a GitHub Security Advisory or by contacting the repository maintainers. Do not include secrets or harmful payloads in a public issue.
