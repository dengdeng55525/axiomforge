## 4. 发现的问题与审查状态

自动规则已经发现：

1. 逻辑回归卡把 predict_proba 放在 metrics 中。它是预测接口，不是评价指标；原始抽取结果如实保留，没有为了展示把原始样例静默改正确。
2. Pipeline、LogisticRegression、ComplementNB 三张卡使用笼统 score。这是依赖估计器的接口名称，不足以替代任务协议中的明确指标 ID。

本轮开发辅助审查还发现以下语义边界：

- 短信卡的摘要使用了“control near-duplicates”。实际协议是大小写／空白规范化后的精确文本组去重，不能保证清除语义近重复或全部模板重复。
- Pipeline 卡列出预测概率作为输出，但其可用性取决于最终估计器支持相应接口；“所有 final estimator 有 fit”不足以保证 predict_proba 存在。
- 业务卡中的指标选择需要与独立任务协议和指标卡对应。引用存在，并不自动证明引用片段中包含全部指标选择依据。

这些是开发阶段逐项比对形成的审查记录，**没有经过独立人工专家双人标注或盲审**，不汇总成“人工语义准确率”。当前执行器使用已批准的任务类型、指标和模型接口，模型抽取的自由文本 metrics 不直接变成可执行评价函数。

后续可增加字段级置信状态：原始 LLM 卡保留为 extracted；经明确规则修正或人工复核的内容另建版本，记录修订者、理由和来源。只有真实运行验证过的实现／修复，才赋予对应运行证据。

## 5. 为什么没有报告 38 条 gold 的 precision／recall

knowledge/extraction_gold.json 包含 38 条开发阶段显式编写的参考断言，形式是：

    subject / predicate / object / source_key

它们是项目整理的来源约束参考集，尚未经过独立人工复核。统计单位是原子字段或关系，多个断言可能共享一个来源或能力，不是 38 个独立能力样本。

本次真实模型返回的是自然语言能力卡，**没有返回上述规范化四元组**。此外，38 条参考中只有 17 条的 source_key 属于本次提供的 10 个来源，另外 21 条超出本次输入范围。

因此当前评估输出为：

    status = unevaluated_schema_mismatch
    precision = null
    recall = null
    f1 = null
    semantic_precision = null
    semantic_recall = null

17/38 仅表示参考断言的来源范围，不是抽取召回率。不使用事后人工“翻译”卡片去构造模型没有实际输出的预测，更不把未提供给模型的来源断言全判成漏召回。

未来若要执行这一项独立评测，可保持 gold 不出现在模型提示中，只提供原始来源、规范化输出 schema 和受控 predicate 词表；冻结模型、提示和来源后，保存模型原始四元组，再调用 evaluate_assertions()。报告应同时给出全部参考数、本次输入范围内参考数、精确匹配分数及语义人工复核结果。精确字符串／四元组一致性仍然不能代表全部自然语言事实正确性。

## 6. 离线复现

项目已安装、官方文档缓存和相同 scikit-learn 版本存在时，执行：

    .venv/bin/python scripts/evaluate_extraction.py

默认读取本地真实记录 artifacts/ingestion/deepseek_extraction.json，输出：

- artifacts/ingestion/extraction_evaluation.json：结构、出处、问题标记、gold 未评估状态和输入 SHA256。
- examples/evidence/knowledge_extraction.json：约 15 KB 的公开可提交样例，只有来源公开定位、能力卡、实际模型标识和汇总 usage。

支持 --input、--gold、--output、--export。脚本只重新读取固定允许清单中的 UCI 文档、项目协议和 sklearn 源码；不会根据模型给出的任意本地路径打开文件。修改文档或依赖版本后产生来源不匹配是应报告的版本漂移，不能静默跳过检查。

完整原始录制位于 Git 忽略的 artifacts 目录；新克隆仓库默认只有公开样例，没有这个原始文件。新用户可先阅读公开样例并运行单元测试；要重算完整“输入片段逐字一致”检查，需要本地保留的原始录制或重新执行明确授权的真实抽取。不要以缺少原始文件为由伪造录制。

公开样例不包含原始文档全文、模型完整请求日志、任意环境字段、API 凭据或绝对私人路径。真实记录的原始卡片内容保留，自动评估结果与修正建议分开呈现。
