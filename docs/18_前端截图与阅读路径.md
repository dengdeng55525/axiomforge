# 前端截图与阅读路径

AxiomForge · 知衡将需求输入、模型配置、算法验证和知识探索组织为连续的研发工作流。本页按使用场景展示八张当前前端截图，并给出每张图的数据来源与复现方式。

## 工作台与任务入口

概览聚合已保存的运行、能力卡片与语义关系。场景卡直接进入银行营销响应或短信垃圾分类任务。

![AxiomForge 工作台概览](images/workbench-overview.png)

创建任务页集中设置自然语言需求、行业数据、模型后端、候选策略和运行预算。截图使用 SMS 任务与离线 Mock 后端，任务描述取自仓库内的历史 API 运行。

![自然语言需求与任务配置](images/task-workbench.png)

## 模型后端与计算资源

模型页展示 DeepSeek、OpenAI Responses、本地 14B 与 Mock 的接入方式。截图读取空密钥默认配置；本地四卡端点来自版本化部署配置，页面明确区分配置存在和服务连通。

![API 与本地模型配置](images/model-settings.png)

GPU 状态栏常驻顶栏，展开后显示四个设备槽位、设备型号、利用率、显存与温度。下图采用**明确标注的 2/4 卡模拟状态**，用于展示已发现和未发现设备同时存在时的交互。

![GPU 状态栏：模拟 2/4 卡可见状态](images/gpu-status-bar.png)

实际部署时，`/health.gpu_status` 与 `/system/gpus` 返回只读 `nvidia-smi` 探测结果。设备可见性和 vLLM 服务健康分别验证；此状态栏不探测推理端点、不下载模型、不修改 CUDA、代理或系统环境。

| 状态 | 含义 | 页面行为 |
| --- | --- | --- |
| `ready` | 可见 GPU 数达到当前预期数量 | 展示设备和即时资源读数 |
| `partial` | 当前可见部分 GPU | 保留全部四个槽位并标出未检测设备 |
| `unavailable` | 未发现设备或没有 `nvidia-smi` | 显示 CPU / Mock |
| `error` | GPU 探测发生错误或超时 | 显示读取失败，保留其他页面功能 |

## 从页面到接口

| 页面 | 关键内容 | 关联接口 |
| --- | --- | --- |
| 概览 | 场景、历史运行、能力数量和关系 | `/runs`、`/capabilities`、`/graph` |
| 创建任务 | 需求、数据协议、后端、搜索和修复预算 | `/config`、`POST /runs` |
| 模型与环境 | Provider、端点池、14B 配置 | `/config`、`/inference/profiles` |
| GPU 状态栏 | 四个设备槽位与资源读数 | `/health`、`/system/gpus` |
| 验证报告 | 候选指标、检查项、修复链和资源 | `/runs/{id}` |
| Agent 观测 | 角色 span、工具调用、Token、事件游标 | `/runs/{id}/agent-trace` |
| Harness 评测 | 终态、事件、角色、候选、预算和脱敏检查 | `/runs/{id}/harness`、`/runs/{id}/harness-suite` |
| 知识探索 | 来源、能力版本与验证路径 | `/graph/explore`、`/capabilities/{id}` |

## 可复现截图

在安装好项目 Python 依赖、前端依赖及 Playwright Chromium 后，从仓库根目录运行：

```bash
npm --prefix web run build
node web/scripts/capture-docs.mjs
```

捕获工具在随机回环端口启动静态服务，使用浏览器请求拦截提供历史证据和界面环境配置。全部截图在本机生成；流程不调用付费模型、不访问外网、不写入实际知识库。

- [`scripts/capture_docs_fixtures.py`](../scripts/capture_docs_fixtures.py)：从已提交报告和内存知识库生成页面快照。
- [`web/scripts/capture-docs.mjs`](../web/scripts/capture-docs.mjs)：打开当前生产构建、执行页面交互并截取八个视图。
- [`images/capture-manifest.json`](images/capture-manifest.json)：记录前端构建哈希、源报告 SHA256、运行 ID、视口、图片哈希和模拟配置范围。

新增截图时保留源报告的状态、候选、指标和事件；环境示例独立标注。报告、知识库来源和制品清单共同承担结果复核，图片提供工程界面的阅读入口。
